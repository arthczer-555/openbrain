# Using AI tools at work (draft)

Status: draft, to be confirmed by the leadership team. Until then, apply these rules.

## Approved tools

Use the AI assistant provided in the company workspace, logged in with your Acme Google account. The security team keeps the list of approved tools.

## What you must never paste

- Client data: tickets, messages, attachments, call transcripts, exports.
- Personal data of colleagues, candidates or contacts.
- Passwords, API keys, contracts and invoices.

This applies to every AI tool that is not on the approved list, including free online chatbots and browser extensions.

## Using the output

- A person reviews anything produced with AI before it is sent to a client or published.
- AI output is never the only basis of a decision about a person, such as hiring.

## Questions

Ask the security team through the security mailbox before you start using a new AI tool.
