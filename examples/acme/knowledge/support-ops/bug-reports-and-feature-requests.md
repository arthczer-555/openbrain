# Bug reports and feature requests

## Report a bug

Level 2 product specialists file bugs in the engineering tracker, after reproducing them. Use the bug template:

- **Steps to reproduce**, and what happens instead of what was expected.
- **Affected companies**, and the number of client users concerned.
- **Severity**, with the same levels as incidents ([Incident severity levels](incident-severity.md)).
- A link to the support ticket. Never paste client messages or personal data into the tracker: the link is enough.

Engineering triages new bugs every morning. The product specialist follows the bug and tells the level 1 agent when a fix ships.

## Log a feature request

Anyone at Acme can log a feature request in the engineering tracker with the label **feature-request**: the need in one sentence, the client or prospect who asked, and the plan of the client. Add a vote to an existing request rather than creating a duplicate.

## What to tell the client

Never promise a date or a feature. Say that the request is logged and that the product team reviews requests every month.
