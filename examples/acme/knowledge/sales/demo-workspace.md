# Demo workspace

Use the demo workspace to show Acme Desk to a prospect. Never use the workspace of a client for a demo.

## What it is

**Acme Demo** is a company in Acme Console on the Enterprise plan, with every channel switched on, sample groups and a few hundred sample tickets. The sample data is reset every night, so changes made during a demo disappear the next day.

## Get access

Ask the customer success team: they invite you as a client user of **Acme Demo** with the supervisor role. Then log in to Acme Desk the way a client would.

## Good practice

- Never type real client or prospect data into the demo workspace.
- For a demo built around the team of the prospect, create a temporary group in **Acme Demo** and delete it afterwards.
- Longer tests by the prospect are done in a [free trial](free-trial.md), not in the demo workspace.
