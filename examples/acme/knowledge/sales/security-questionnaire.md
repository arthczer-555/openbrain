# Answers to client security questionnaires

Use these answers as they are. For a question not covered here, ask the security team through the security mailbox before answering.

## Hosting and encryption

Acme Desk is hosted in the European Union. Data is encrypted in transit and at rest. We do not offer on-premise hosting.

## Access and authentication

Client users log in with a password and can use two-factor authentication, which a client admin can make mandatory. Single sign-on (SAML) is available on the Enterprise plan. Acme staff only see the tickets of a client when a client admin grants a support access ([Open a client workspace as support](../admin/support-access.md)).

## Retention

Ticket data follows the product rule: closed tickets are kept for 24 months after closure, then deleted automatically, attachments included. The reference page is [Data retention in Acme Desk](https://www.notion.so/acme/Data-retention-in-Acme-Desk-916af458454bc8e3fc7fe583aa63bb72).

## Certifications and tests

ISO 27001 certification is in progress: never answer that Acme is certified. An external penetration test runs every year and its summary is shared under NDA. See [Certifications and audits](../legal-security/certifications.md).

## Sub-processors

The list of sub-processors is sent on request with the data processing agreement ([Subprocessors](../legal-security/subprocessors.md)).
