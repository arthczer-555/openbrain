# Data export

## Export tickets yourself

A client admin can export tickets as a CSV file from **Settings** then **Data export**, on every plan. Pick a date range and the groups; the file is emailed to the client admin when it is ready. The CSV contains the ticket fields and messages, without attachments.

## Full export with attachments

For a complete export, including attachments and call transcripts, a client admin asks Acme support. The export is delivered as a secure download link within 10 business days. It is the usual path for a client that leaves Acme ([Client offboarding](../admin/client-offboarding.md)).

## What is not exported

Reports, automation rules and macros are not part of an export. Tickets already deleted under the retention rules cannot be exported ([Data retention in Acme Desk](data-retention.md)).
